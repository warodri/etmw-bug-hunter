ETMW Bug Hunter agent

The download already contains your account token. Treat the ZIP like a key: anyone who has it can pair an agent to your account.

Requires Node.js 20 or newer. Install it from nodejs.org if the installer reports that it is missing.

  1. Download the ZIP with the button above. It already contains your token.
  2. Unzip it and open a terminal in that folder.
  3. Run the installer with the commands in “Start it from the Terminal” below.
  4. The agent starts now and again every time the computer starts.
  5. Add a project, choose “Desktop agent”, and pick this computer.
